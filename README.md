# Video Grabber Pro (無制限版 動画ダウンローダー)

Video DownloadHelperの制約（特定サイト制限、コンパニオンアプリ要求、課金ロックなど）を排し、ブラウザ内で完結して動画ストリームを検出・取得するChrome拡張機能（Manifest V3対応）です。

---

## 🚀 主な特徴・制限解除ポイント

1. **外部コンパニオンアプリ不要**
   - 専用ソフトのインストールや常駐が不要で、ブラウザ単体で完結します。
2. **多重検出エンジン ＆ 強制検出（Super Reload）**
   - **キャッシュ破棄リロード**: ログイン状態を保ったまま、キャッシュを無視してページ通信を再走査。
   - **Cookie削除＆強制リロード**: 本家 VDH の `button_super_reload` と同じ処理（Cookie 削除＋キャッシュ無視）。親ドメイン（`.example.com`）の Cookie も削除します。
   - **ネットワーク層 (`chrome.webRequest`)**: 通信を見張り、MP4（`.mp4` / `.m4v` / `video/mp4`）と HLS（`.m3u8` / `mpegurl`）を自動キャッチ。途中で止まるストリーミング再生も検出。
   - **DOM スキャン**: `<video>`, `<source>`, `og:video` を抽出。更新ボタンで `<script>` 内の URL も再スキャン。
   - **ページ内フック (`inject.js`)**: ページ読み込み直後から fetch / XMLHttpRequest / `video.src` をフック。
3. **HLS（m3u8）対応・回数制限なし**
   - 細切れ配信の部品を全部取ってきて 1 本につなぎます（`hls-engine.js`、裏で `offscreen.js` が実行）。ポップアップを閉じても続きます。
   - 最高画質を自動で選択。AES-128 暗号化も解除。fMP4 形式は `.mp4`、それ以外は `.ts` で保存。
   - 対象外：DASH（mpd）、DRM（SAMPLE-AES / Widevine）、音声が別ファイルの配信（映像だけになります）、音声ファイル。
4. **一括ダウンロード & ワンクリックURLコピー**
   - 「一括ダウンロード」は保存先を聞かずに `ダウンロード/VideoGrabber/` へ保存します（HLS は 1 本ずつ順番に処理）。

---

## 📦 インストール方法（Chrome）

1. Google Chrome を開き、アドレスバーに `chrome://extensions` と入力して開きます。
2. 右上の **「デベロッパー モード」** を **ON** にします。
3. 左上に表示される **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. このリポジトリをクローンしたフォルダ（`manifest.json` があるフォルダ）を選択します。
5. ツールバーのパズルピースアイコンから「Video Grabber Pro」をピン留めします。

---

## 💡 使い方

1. 動画が埋め込まれているWebページを開き、動画を再生（またはロード）します。
2. ツールバーのアイコンに検出された動画の件数バッジが表示されます。
3. アイコンをクリックしてポップアップを開きます。
   - **「ダウンロード」**: 指定ファイルをそのまま保存。
   - **「URLをコピー」**: リンクをコピー。
   - **「一括ダウンロード」**: 検出された動画をすべて保存。
